# 工作台共享接口规范（v1.0）

本文件固定 **模型、搜索、审稿、任务状态** 四类共享接口；子智能体 A（接入）、B（流水线）、C（菜单）必须遵守。修改需经主线程批准。

## 1. 模型接口

```python
@dataclass
class ModelRequest:
    role: Literal["planner", "writer", "reviewer"]
    messages: list[dict]            # OpenAI Chat Completions 消息格式
    temperature: float | None = None
    max_tokens: int | None = None
    request_model: str              # 配置中固定，不允许运行时替换
    snapshot_id: str                # 引用 [task.snapshot_id]，禁止跨期串用

@dataclass
class ModelResponse:
    text: str
    request_model: str              # 发出请求时声明的模型
    served_model: str               # 服务端实际返回的模型别名
    usage: dict[str, int]           # prompt_tokens / completion_tokens / total_tokens
    raw_error: str | None = None    # 非空时表示失败，text 不可信
```

约束：
- 返回模型别名差异**仅写入诊断日志**，不据此认定「调了错误模型」；岗位由 `request_model + snapshot_id` 双重决定。
- `raw_error` 非空即视为失败，调用方不得静默降级或换模型重试（认证失败除外，参考下文）。
- 超时 180s；网络错误与限流最多重试 2 次；认证失败（HTTP 401/403）直接停止并提示用户。

## 2. 搜索接口

```python
@dataclass
class SearchSource:
    id: str                         # 渠道内稳定编号，证据绑定用
    url: str
    title: str
    publisher: str | None           # 发布方/作者
    published_at: str | None        # 发布日期，ISO 8601
    accessed_at: str                # 实际抓取日期，ISO 8601
    excerpt: str                    # 摘要或截取片段
    locator: str | None             # 段落/章节/页码定位
    body_path: str | None           # 全文落地路径（无则为空）
    status: Literal["ok", "paywall", "captcha", "fetch_failed", "pdf_unparsed"]
    channel: Literal["tavily", "brave", "bing"]
```

约束：
- 关键事实必须绑定 `SearchSource.id`；摘要仅用于发现原文，不得作为唯一证据。
- 渠道受限时 `status` 显式标注，不允许用其他渠道结果补齐缺失事实。
- MCP 启动：stdio 必须先做工具发现；http 必须先 ping `/mcp` 握手。
- 深入检索最多 2 轮、30 个去重来源、站内深度 2 层。

## 3. 审稿接口

```python
@dataclass
class ReviewIssue:
    severity: Literal["block", "major", "minor"]
    category: Literal[
        "fabricated_citation", "unsupported_key_fact",
        "out_of_scope_sample", "fake_personal_experience",
        "stale_version", "tone", "structure", "fact", "other",
    ]
    location: str                   # 段落定位或证据编号
    description: str
    evidence_source_ids: list[str]  # 引用的事实必须挂源
    suggestion: str | None

@dataclass
class ReviewVerdict:
    draft_version: str              # 与 [task] 中稿件版本绑定
    issues: list[ReviewIssue]
    score: float                    # 0-100
    recommendation: Literal["draft_1", "draft_2", "draft_3"]
    pass_: bool                     # 关键阻断项未触发时为 True
```

约束：
- `severity == "block"` 的条目数 > 0 → `pass_ = False`，且 `score` 不得单独把它救活。
- 必阻断类别：`fabricated_citation / unsupported_key_fact / out_of_scope_sample / fake_personal_experience`。
- 复审输入必须含上一轮 `ReviewVerdict`，并对每个 block 项给出处理结果（已修 / 不修并说明）。

## 4. 任务状态

```python
@dataclass
class TaskState:
    issue_id: str                   # YYYY-MM-DD-HH-MM-SS-专栏
    stage: Literal[
        "topic_selection", "evidence_collection", "planning",
        "draft_1", "draft_2", "draft_3",
        "review_1", "revise_1", "review_2", "revise_2",
        "awaiting_human", "finalizing", "archived",
    ]
    versions: dict[str, str]        # 每个阶段的产出文件路径 + 内容哈希
    snapshot_id: str                # 引用本期模型快照
    last_checkpoint_at: str         # ISO 8601
    rerun_invalidated: list[str]    # 被标为过期的下游阶段
```

约束：
- 阶段完成后**原子写入** `进行中/<issue>/运行记录/checkpoint.json`（先写 `.tmp` 再 rename）。
- 重跑上游 → 当前阶段及之后全部 `rerun_invalidated`；恢复时禁止混用旧版本与新版本。
- 两轮返修（`revise_2`）后仍未通过 → 自动转入 `awaiting_human`，**不再自动继续**。
- 自动流程不得写 `finalizing` 与 `archived`；这两步由用户在 5/6 号菜单确认。

## 5. 调用限制汇总

| 项 | 上限 | 超出行为 |
|---|---|---|
| 模型超时 | 180s | 计入重试 |
| 网络/限流重试 | 2 次 | 仍失败则降级到公开搜索或停步 |
| 认证失败 | 0 次 | 直接停止并提示 |
| 深入检索轮数 | 2 轮 | 进入 `evidence_collection` 完成态 |
| 去重来源 | 30 个 | 停止新增 |
| 站内深度 | 2 层 | 停止下钻 |
| 返修轮数 | 2 轮 | 进入 `awaiting_human` |
