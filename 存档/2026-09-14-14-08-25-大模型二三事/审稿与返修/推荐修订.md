# 返修稿 2：纯文本 LLM 不是"被终结"，而是被迫"降级为世界模型的一个子系统"

看到“纯文本时代正在终结”这样的标题，你不必感到恐慌，也别全信这种非黑即白的叙事修辞。技术现实的演进从来不是戏剧性的断裂。过去两年，我们见证了参数量的狂飙，仿佛数字越大，通用人工智能的曙光就越近。但现在，纯粹的“参数规模竞赛”正在失去魔力，纯文本预训练的收益递减信号已经非常明显 [bing-0-2]。继续往模型里塞入海量的合成文本，它变聪明的程度，远远赶不上算力成本和电费上涨的速度。在这个背景下，我们需要重新审视纯文本大语言模型（LLM）的位置。它并没有被扔进历史的垃圾桶，但在许多前沿探索中，它正面临一次深刻的角色重构。

在 Yann LeCun 等学者提出的架构蓝图中，纯文本 LLM 正被重新定义为世界模型的语义接口，而非独立的核心引擎。请注意，这目前更多是顶尖学者眼中的技术演进方向，而非全行业已经落地的既成事实。但在这种极具前瞻性的构想里，LLM 被迫“降级”了。它退守为世界模型的语义接口与人机对话层。真正决定下一代 AI 上限的，不再是那个能预测下一个词的文本引擎，而是其背后那个能预测物理后果、能在动作空间里反推路径的世界模型组件。这种视角的转换，意味着我们评估 AI 能力的标尺，正在从“它知道多少人类知识”转向“它能在物理世界中做对多少事”。

我们可以拆解一个具体的具身任务来理解这种角色重构。假设你让一个机器人去厨房倒一杯水。自然语言指令是“倒水”。LLM 负责理解这句话，并将其拆解为一系列高层动作序列：“寻找水杯”、“移动过去”、“抓取水杯”、“寻找水壶”、“倾倒”。到这里，LLM 的语义解析工作就结束了。但是，机械臂该怎么移动？关节需要弯曲多少度才不会撞翻旁边的碗？抓取水杯时手指需要施加多大的力才能既不滑落又不把杯子捏碎？倾倒时水壶的角度和速度如何配合才不会让水溅出来？这中间存在一个不可压缩的物理预测环节。LLM 可以输出数值，但它无法计算出符合物理现实约束的准确参数。缺乏物理反馈的 LLM 无法确保动作的有效性，因为它从未在物理世界中生活过。它只知道“倒水”这两个字符在语料库中经常和“杯子”、“水壶”一起出现，却不知道水在重力作用下的流体力学表现。填补这个物理预测空白的，才是世界模型。

很多人误以为世界模型就是“大模型 + 视频生成”，这是极大的误解。世界模型需要三件套：状态空间、动作空间、反事实推演 [brave-0-3]。状态空间是理解系统当前的物理状态，比如水杯的精确三维坐标、水壶的重量与重心；动作空间是知道系统能执行哪些物理操作，比如机械臂的六个自由度、夹爪的开合毫米数；反事实推演是预测“如果我执行动作 A，状态会如何转移到 B”。

在这个框架下，我们必须厘清纯文本训练的边界。纯文本训练无法建立物理世界的因果体验，它缺乏物理交互的反馈闭环。文本数据中确实包含大量物理规律的描述，模型在统计层面也“覆盖”了这些语义分布，但这与真正的物理接地是两码事。文本里写“杯子掉在地上碎了”，模型只是记住了字符的共现概率与上下文关联。而世界模型需要在数学和物理空间里，真正模拟杯子掉落、碰撞、碎裂的物理轨迹，计算出能量守恒与动量转移。文本给的是“世界的说明书”，而世界模型需要的是“世界的物理引擎”。

Yann LeCun 的 JEPA（联合嵌入预测架构）体系，早就在重新定位语言模型的角色 [brave-0-14]。在他的构想中，语言模型只是联合嵌入预测架构里的一个组件，负责处理符号和语义，而真正的世界理解发生在连续的表征空间中。我们可以对比一下视频生成模型和世界模型的能力边界 [brave-0-17]。视频生成是像素层面的接龙，它追求的是画面看起来逼真，符合人类视觉的统计规律；世界模型是物理规律的推演，它追求的是物理逻辑的正确。一个能生成完美水滴下落视频的文生视频模型，未必能计算出水流冲击杯底的反作用力。在 JEPA 的蓝图中，LLM 被剥离了“全知全能”的光环，成为了连接人类意图与物理引擎的翻译官。

在这个新架构里，LLM 的真实角色变成了“语义编解码器”。它负责把人类模糊、充满歧义的自然语言意图，翻译成机器能理解的状态变量；同时，把机器的物理动作结果，翻译回人类能懂的语言。它不再是“世界知识库”的唯一载体。因此，评估它的指标也应该发生根本性的转变。过去我们热衷于用 MMLU 这种考察静态知识储备的做题分数来衡量模型智商，但在具身智能和物理交互的语境下，这些分数显得苍白无力。真正的试金石是真实环境中的任务成功率 [bing-0-5]。一个能在 MMLU 上考 90 分的模型，如果让它在杂乱的房间里找到一把特定颜色的钥匙并递给人类，它可能会因为无法识别被部分遮挡的钥匙而彻底卡壳。

当然，我们需要严格区分学术蓝图与产业现状。目前，全行业并没有一夜之间抛弃纯文本 LLM。相反，当前的产业实践更多是在探索如何将强大的文本 LLM 与正在成长的世界模型进行耦合。比如，当前热门的 VLA（视觉-语言-动作）模型，就是试图将 LLM 的语义理解能力与视觉编码、动作生成直接绑定。大厂们在自动驾驶和机器人领域的探索，本质上都是在寻找文本逻辑与物理反馈的最佳耦合点。利用 LLM 强大的常识推理能力来规划高层任务，再将这些任务下发给基于强化学习或物理仿真训练的低层控制策略，这是一个过渡期的务实选择。但长远来看，随着物理世界数据采集成本的降低和算力向多模态、连续空间的倾斜，世界模型在架构中的权重必然会越来越大。纯文本 LLM 的“降级”，本质上是 AI 从“纸上谈兵”走向“脚踏实地”的必经之路。

这对从业者意味着什么？如果你在做应用层，不要只盯着 API 调用和提示词工程了。去了解一下机器人学、运动学和控制论的基础，理解物理世界的约束。你需要知道，在代码里调用一个“抓取”函数，和在现实世界中让一个五吨重的机械臂在不平整的地面上稳定抓取，中间隔着多少物理学的鸿沟。如果你在做基础研究，next-token（预测下一个词）的范式，可能真的要向 next-state（预测下一个物理状态）让位了。你需要思考如何设计更高效的架构，让模型能够在连续的物理空间中直接进行推演，而不是强行把物理状态离散化成文本 token。

技术的演进从不以个人的意志为转移。纯文本 LLM 的“降级”，不是它的失败，而是 AI 迈向真正通用智能的成熟标志。当我们不再迷信文本世界里的文字游戏，开始敬畏物理世界的复杂与真实时，我们才真正走在了正确的道路上。

这是技术演进的必然，也是从业者的责任。

—— 写稿岗
