| 关于公布“人工智能时代的审计（2026）”专题研讨会入选论文名单的通知 |
|  |

|     |
| --- |
| 【时间:2026年05月28日】 【来源:中国审计学会】字号： 【大】【中】【小】 |

|     |
| --- |
| 2026年2月，中国审计学会秘书处和审计署审计科研所发布征集“人工智能时代的审计（2026）”专题研讨会论文的通知，截至4月27日，共收到论文596篇。经过专家评审，35篇论文入选。现将名单公布如下：<br>1.《生成式人工智能嵌入数据式审计：内在逻辑、应用范式与实施路径》，作者：高思凡、房巧玲，作者单位：厦门国家会计学院、中国海洋大学<br>2 .《专家系统与大模型协同驱动的智能审计框架研究》，作者：陈勇、邱诗媛、徐超、黄佳佳，作者单位：南京审计大学、江苏省人工智能审计研究院<br>3 .《人工智能时代的审计证据可靠性危机与法律转化——基于审计标准向诉讼标准转化的分析框架》，作者：杜宏伟，作者单位：审计署审计科研所<br>4.《基于AI技术的国有企业重大风险识别与审计路径研究》，作者：樊融，作者单位：四川省审计厅<br>5.《国家审计中人工智能伦理冲突的治理框架：责任追溯与制度协同》，作者：陈章顺、陈妍丽，作者单位：江苏省徐州市审计局<br>6.《人工智能技术获取审计证据的可靠性与证明力研究》，作者：兰健、陈怡璇，作者单位：浙江省审计厅、浙江省审计科学研究所<br>7.《AI赋能审计数据治理的协同机制研究——基于浙江省的实践》，作者：喻贞、翟浩东、李硕硕，作者单位：浙江财经大学、中国资源循环集团有色金属投资有限公司<br>8.《AI+审计时代的数据治理——以中移系统集成公司实践为例》，作者：贾春艳、赵旭升，作者单位：中移集成系统有限公司<br>9 .《人工智能在政府网络安全与审计中的应用及风险应对研究》，作者：周斌，作者单位：浙江省审计厅<br>10.《人工智能时代国家审计数据安全的法律保障机制研究：风险谱系与制度回应》，作者：董学成，作者单位：审计署上海特派办<br>11.《人工智能时代的国有大型建筑业审计数据治理——构建审计大模型及智能体的数据基石》，作者：毛莉、邬章、陈联和、陈爱青、彭肖，作者单位：中建三局集团有限公司<br>12.《监管新规导向下的“人工智能+审计”双向风险及防控策略》，作者：郭凯东、杨涛，作者单位：审计署兰州特派办<br>13.《人工智能嵌入国家审计的技术风险、法治困境与规范进路》，作者：张荣刚、李英楠，作者单位：西北政法大学<br>14.《基于角色和任务的审计多智能体框架设计、研究与实现》，作者：刘锦，作者单位：上海市审计科学研究所<br>15.《面向审计大模型应用的语料治理框架研究》，作者：山东省审计厅课题组，作者单位：山东省审计厅<br>16.《基于“1+2+N+4”为核心的审计智能体构建和应用研究——以A市为例》，作者：张淳淳、戴俊奕、钟萌萌、王丁贵、戴旭、董永明，作者单位：浙江省杭州市审计局<br>17.《审计智能体：算法与AI双轮驱动的审计范式转型研究——以虚假贸易识别为例》，作者：曹勇、郭艳军、朱海，作者单位：中粮集团审计部<br>18.《面向自然资源资产离任审计的智能体框架构建与应用研究》，作者：韦小儒、邵渝森、王博、陆志元，作者单位：广西壮族自治区地理信息测绘院、桂林理工大学、广西壮族自治区审计厅<br>19.《审计整改智能体的构建与应用研究——以H高校为例》，作者：陶玲、戚闽粤、陈立为、申君、熊文、韩云金，作者单位：华南农业大学、广东省审计厅、中国邮政储蓄银行审计局广州分局<br>20.《基于大语言的审计智能体构建与应用》，作者：金华杰、张锴杨、冯超，作者单位：重庆市审计局<br>21.《基于AI赋能围标串标精准治理的投资审计智能体构建与应用》，作者：高勇、崔占香，作者单位：山东省审计厅<br>22.《审计智能体的成熟度模型构建与应用——以审计争议场景为例》，作者：牛艳芳、田帅、王树来、李琦，作者单位：山东财经大学、山东高速集团有限公司<br>23.《从感知到执行：以OpenClaw为框架的审计智能体》，作者：陈亚盛、叶紫、吴霆声、庄平、卢章芳，作者单位：厦门大学、国网福建省电力有限公司<br>24.《智审乡土：人工智能技术在农业农村审计领域的应用场景与模型构建研究》，作者：张彬，作者单位：审计署广州特派办<br>25.《大语言模型在社会保障审计中的应用研究》，作者：赵东晓、赵朗、张海涛，作者单位：江苏省南京市审计局、江苏省审计厅、南京审计大学<br>26.《混合智能驱动的国家审计人机协同架构与应用范式-基于云南“云端问审”平台实践》，作者：罗莉、周忠伟、吴凯、张晋津、赵继雯、王磊，作者单位：云南省审计厅、南京审计大学<br>27.《基于人工智能的高标准农田审计应用研究》，作者：刘峰、刘朝蒴、彭邵城，作者单位：山东省禹城市审计局<br>28.《企业审计智能化转型的架构设计与场景验证研究——基于“研究侧—作业端”双轮驱动的实践探索》，作者：万钧、董莼、周瑛寅，作者单位：浙江省审计厅、浙江省舟山市审计局、中科天翔（杭州）科技有限公司<br>29.《多模态审计数据融合分析的实践路径研究》，作者：陈永泰、朱杰、从洁，作者单位：南京审计大学、江苏省常州市审计局、国家石油天然气管网集团有限公司北方审计中心<br>30.《AI驱动下的审计范式重构：广东资源环境智能审计的实践创新与进阶路径》，作者：韦炜，作者单位：广东省审计厅<br>31.《生态环境审计中隐蔽性污染行为的AI识别与监管治理研究》，作者：夏鹏、夏传真、卢建勋、邱晓娜，作者单位：山东省审计厅<br>32.《AI Coding在政府审计实战中的应用研究》，作者：张彦男、田径，作者单位：上海市审计局<br>33.《人工智能时代下财政审计应用技术研究与思考——以某区预算一体化系统项目分析为例》 ，作者：耿冬艳、王宇轩、单君媛，作者单位：北京市通州区审计局、北京市审计局<br>34.《基于“人工智能+无人机”的电网工程审计领域应用场景》作者：林荣聪、梁昕、郑峰、蔡晓妍、谢博约、柯志伟、黄先武，作者单位：国网福建省电力有限公司综合服务中心<br>35.《基于DeepSeek+Coze的高值医用耗材审计智能体技术路径设计与应用研究-以Y医院为例》，作者：邓颖莹、何结宗、肖文娟、宋文昭，作者单位：广西医科大学第一附属医院、南宁市第一人民医院<br>中国审计学会秘书处
